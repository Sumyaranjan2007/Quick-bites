## Common to all four

| Thing | Where | Note |
|---|---|---|
| Entry and navigation | `apps/<app>/App.tsx` (state-based screen switch, no router library) | customer: `type Screen` at `App.tsx:41` |
| Server address | `src/config.ts:13` `DEFAULT_API_URL` = live `/api` | changeable on the phone: **6 quick taps on the sign-in logo → "Server settings"** (`src/lib/useHiddenSettings.ts:24`, used by the sign-in screen) |
| HTTP | `src/lib/apiFetch.ts` (+ `src/lib/api.ts` in Rider/Admin, `src/lib/partnerApi.ts` in Partner) | Admin's client already returns `payload.data`: never read `.data` twice (`CLAUDE.md` §8) |
| Expired sign-in | every app returns to sign-in on `INVALID_TOKEN` / `SESSION_REVOKED` | 7-day tokens (`authRouter.ts:51`) |
| Push | `src/lib/pushRegistration.ts` → `POST /api/devices` | channels: `docs/NOTIFICATIONS_AND_TRACKING.md` |
| Modals | `src/components/Modal.tsx` (pads under Android bars) | never import Modal from `react-native` |
| Maps | `src/lib/nativeMap.ts` (Customer, Partner, Rider) | `LocationPuck`, never `UserLocation` (`nativeMap.ts:256` comment) |
| Languages | Customer `src/lib/i18n.tsx` (en, hi, kn); checked by `scripts/check-i18n.mjs` | – |
| Version | `app.json`: version 1.4.0; versionCode Customer 32, Partner 32, Rider 33, Admin 32 | `release/version.json` = 33 |
| Native folders | `android/`, `ios/` generated by `expo prebuild`, gitignored | config plugins in `packages/config/expo-plugins/` |
