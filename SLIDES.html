Architecture 04 / 08

Engineered as a Modular Monolith

Zero network latency between domain modules, with strict logical boundaries.

Relational + Document Hybrid DB

PostgreSQL (Supabase) handles ACID financial transactions, user accounts, and PostGIS spatial radius queries.

MongoDB Atlas stores complex, flexible nested menu hierarchies, toppings, and customer reviews.

Sub-50ms Real-Time Search & Cache

Upstash Redis token buckets enforce rate limits and cache active order states.

Meilisearch Cloud handles instant typo-tolerant searches across thousands of dishes and eateries.
